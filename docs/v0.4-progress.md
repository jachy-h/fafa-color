## 实施日志

- **起**：v0.4-plan.md 落定，明确「数字画廊」方向；先完成 4.0 文字存在感微调（上一会话）并验证构建。
- **copy.js 新增**：从 `name.js` 的 `SEGMENT_NAMES` 派生 8 个展厅（room / words / blurb / 色域），新增 `MANIFESTO`（策展词）与 `VISIT_GUIDE`（参观指南），文案全部集中在 `copy.js`，便于日后多语言扩展。

- **4.2 chapters 视图**：`VIEWS` 增为 4 段；卡片用 `button.chapter-card` 一次性构建并缓存；`.view-chapters` 允许纵向滚动（`overflow-y:auto; touch-action:pan-y`）；wheel 切换视图增加 chapters 守卫（避免滚动时切视图）。
- **4.3 聚光**：`spotlightSeg` 全局态；`applySpotlight()` 给非展厅 cell 加 `.dimmed`（0.16 opacity + grayscale 0.45）；`enterChapter(i)` 由卡片点击 / About 目录触发 → 切到 grid 视图；chip 位置下移至 tagline 之下避免重叠。
- **4.4–4.5 字体**：`:root{--serif}`；`#focus-name` 重排为 22px（移动端 18px）衬线细体作品标题；`#splash-tagline` 新增并带 8s 呼吸。
- **4.6 作品页**：`enterFocus` 的 hex 文本改为 `#fafaxx · 第 N 展厅`；`focusStep(dir)` 在 seg 内循环切换（`SEG_WIDTH=32`）；touch 滑动改判：左右滑动=切色，点击=退出（用 `focusSuppressed` 阻止滑动后的误触点击）；桌面方向键 `←/→` 切色、`Esc` 退出。
- **4.7 About**：`#about` overlay（z-index 150，blur 背景）；策展词按行拆 `<p>` 渲染；目录按钮 `data-seg` 直达 `enterChapter`；修复了「先塞 textContent 又清空」的渲染 bug。
- **4.8 渐变**：`segmentGradient(b)` 供 view 涟漪使用；`withAlpha(rgb,a)` 把 `rgb()` 转 `rgba()`，`renderFocusChrome` 用它为 `.focus-glow` 构造多色 radial。
- **4.11 引导动画**：新剧本 `v0.4-guide-script.md`（5 幕：拂晓/命名/展开/展厅/邀请，约 29s）。
  - `#guide` 全屏 overlay（z-index 180），5 个 `.g-scene`；幕内揭示全部走 CSS `animation-delay`，播放引擎只负责切幕（`setTimeout` 链 + 进度点）。
  - 迷你色元素由 JS 生成：命名幕 32 格色带 + 扫描光斑 + 3 个名字；展开幕 4 个微型视图（色条/网格/圆环/卡片）；展厅幕 8 张卡片（复用 CHAPTERS）。
  - 交互：任意点击 / 跳过按钮 / Esc → `finishGuide()`（0.5s 淡出后 `enter()`）；`localStorage[fafa:guide:v1]` 记忆看过/跳过；`prefers-reduced-motion` 直接 `enter()`。
  - 将 `enter()` 拆出 `fadeSplash()` 复用；`handleSplash` 用 `splashEntering` 防 pointerdown+click 双触发。
- **4.12 `[hidden]` 修复**：冒烟测试发现 `#focus{display:flex}` 覆盖 UA 的 `[hidden]{display:none}`，导致 `#focus` 常驻整页并拦截点击（开屏点击、色块交互实际都被挡）。在 `style.css` 顶部加 `[hidden]{display:none!important}` 全局复位，`#focus/#about/#guide/#tooltip/#stage` 等所有 `hidden` 语义恢复正常。

## 技术要点

- **展签文案结构**：`updateWallLabel(b)` 以「当前作品 + 所属展厅」两行结构承载信息，与 `#tooltip`（跟随指针的即时提示）职责分离：tooltip 临时、展签常驻。
- **chapters 滚动 vs 视图切换**：chapters 内 `overflow-y:auto` + `touch-action:pan-y` 允许纵向滚动；`wheel` handler 在 chapters 视图直接 return，让原生滚动接管，同时横向滑动仍可切换视图。
- **聚光性能**：只在 `spotlightSeg` 变化时批量 toggle class，256 个 cell 只做 opacity/filter 过渡，无布局抖动。
- **作品页手势**：touch `touchend` 判定 `|dx|>60 && dt<600ms` 后设 `focusSuppressed=true` 再 `focusStep`，屏蔽紧随其后的 `click` 退出事件，避免「滑动即退出」。
- **渐变复用**：`segmentPalette(seg)`（name.js 原有）同时供涟漪与沉浸页氛围光使用，保证每间展厅的光色一致。
- **文案集中**：所有可本地化文案（导览语/策展词/指南）收敛进 `copy.js`，与逻辑解耦。
