# fafa · 引导动画剧本（v0.1）

> 一句话：用约 29 秒的电影，让第一次来的人理解「256 个有名字的颜色」——
> 从黎明的一束光开始，看颜色被命名、被排布、被收藏进八间展厅，最后被邀请去点击。

## 0. 概念

站点本身是一座「数字画廊」：256 个 `#fafaxx` 颜色，每一个都有一个手写的名字，住在八间展厅里。
引导动画不做功能演示，而是把这件事当作一个故事讲一遍——文案极少，色彩与字形是演员。

## 1. 目标与原则

| 原则 | 说明 |
| --- | --- |
| 只讲一个故事 | 名字 = 颜色，颜色 = 名字 |
| 可跳过 | 任意点击 / 「跳过」按钮立即进入；老访客不再重播 |
| 颜色是演员 | 大段的戏交给色带、网格、环形与展厅卡片，文案只作画龙点睛 |
| 顺带教学 | 四种视图、八间展厅、点击进入，都被「演」出来而非列出来 |
| 克制 | 无音效、零新依赖；`prefers-reduced-motion` 下直接跳过引导 |

- **结构**：开屏（现状）→ 引导 5 幕 → 舞台（band 视图）
- **老访客**：`localStorage[fafa:guide:v1]` 为真则点击开屏直接进入舞台

## 4. 技术规格

- `#guide` 全屏 overlay（z-index 180）；5 个 `.g-scene`，切换 = 加/去 `.on`。
- **幕内揭示全部用 CSS**：`.g-scene.on` 下的子元素用 `animation-delay` 编排，播放引擎只管切幕。
- 播放引擎：`setTimeout` 链 + 5 枚进度点。
- 跳过：任意点击 / 跳过按钮 / `Esc` → `finishGuide()` → `enter()`。
- 记忆：`localStorage[fafa:guide:v1]`；看过或跳过即写入，下次直接进入。
- `prefers-reduced-motion`：点击开屏直接 `enter()`，不播引导。
- 零新依赖。
