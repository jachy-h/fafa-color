# fafa-color · 进度记录 (v0.6)

> 目标：去繁归简。把故事感和交互感做成循环——向上滚动推进故事，256 个颜色依次展示，讲完后无限循环回到开头。加入时间感。精简到只剩叙事核心。

## 设计决策

| 保留 | 去掉 |
| --- | --- |
| 开屏拂晓光 + 标语 | 引导动画（5 幕） |
| 全屏颜色沉浸 | 展厅分类（chapters/band/grid/ring） |
| 颜色名 + hex 展签 | 收藏系统（favs.js） |
| 向上滚动/上划/点击推进 | PNG 导出（exporter.js） |
| 256 色无限循环 | 三连击烟花彩蛋 |
| 今日时刻标签（顶部居中） | 关于页 / 展签系统 / 聚光 |
| 氛围光 + 大字水印 | 视图切换（4 视图循环） |

## 核心机制

**叙事循环**
- 进入后展示 b=0（`#fafa00` 黎明柠檬）
- 向上滚动 / 上滑 / 点击 / 空格键 → b+1
- b=255（`#fafaff` 雪原纯粹）→ 循环回 b=0
- 每次颜色切换：背景 0.5s CSS transition，名字/hex 渐入，400ms 防连续触发锁

**时间感**
- 顶部居中：`HH:MM · fafa的××` 一行
- 算法：`b = Math.floor((秒数 / 86400) * 256)`，一天 86400 秒均匀映射 256 色
- 每分钟更新，对齐整分钟（setTimeout 对齐 + setInterval）
- 左侧 7px 圆点，颜色取自当前时刻对应的 fafa 色（CSS 变量 `--now-color`）

**手势支持**
- 鼠标滚轮向上（deltaY < 0）
- 触摸上滑（dy < -40 && dt < 600ms）
- 键盘 ↑ / → / 空格
- 点击/tap 整个舞台
