## 技术要点

- **命名库**：纯函数 `nameOf(b)`，段内 32 色按 3 词循环分配，零副作用
- **沉浸页水印**：主题词用 SVG data URI 平铺，配合 `background-repeat` + `blur(2px)` + `opacity 0.7`
- **沉浸页命名**：左下角 `#focus-name` 12px 等宽小字浮出，与右下 `#focus-hex` 并存，移动端 1100ms 长按
- **侧滑退出**：触摸起点 X 到释放 X 偏移 > 60px 且 < 600ms 时退出 focus
- **导出 PNG**：1080×1080 canvas，每格 67.5px，0 间隙，时间戳文件名 `fafa-palette-YYYYMMDD-HHMMSS.png`
- **导出反馈**：白闪 `#flash` 110ms 淡入 + 600ms 淡出，z-index 200
- **粒子彩蛋**：60~120 粒子，重力 0.15 + 阻力 0.985，存活衰减 0.012~0.022/帧
- **三连击**：600ms 内同色 3 次；6s 窗口清零；减动效降级为 flash
- **fafa 光斑水印**：70vmin 字号 + blur(12px) + opacity 0.18，2s 淡入淡出
