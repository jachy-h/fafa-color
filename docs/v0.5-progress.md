## 实施日志

- **新增文件**：`src/today.js`（今日之色算法）、`src/favs.js`（收藏 + 上次停留 localStorage 读写）。
- **5.0 today.js**：`todayB()` 算法——`dayOfYear`（从 1 月 1 日算起的 0-based 天数）加上 `year % 256` 作为年份种子，对 256 取模。同年同天确定唯一，无需服务端。
- **5.1 favs.js**：完整的 CRUD API（`getFavs / isFav / addFav / removeFav / toggleFav / favsCount`）+ `setLast/getLast`。`addFav` 返回 `{ ok, full }` 供 toast 判断；所有 localStorage 操作包裹 try-catch 静默失败。
- **5.2 开屏光晕**：用 IIFE `applyTodayDawnGlow()` 在 `<head>` 动态注入 `<style>` 覆盖 `#splash::before` 的 radial-gradient，颜色取自 `rgb(FA, FA, TODAY_B)`，保持与主色调同色域。
- **5.3-5.4 展签**：`#wall-label` 新增第三行 `#wall-today`（8px monospace, 0.28 alpha）。`showWallDefault()` 统一处理默认态（含 `opts.lastB` 临时覆盖），`updateWallLabel(b)` 交互态隐藏第三行以聚焦当前颜色。
- **5.5 上次停留**：`enterFocus()` 调用 `setLast(b)`；`enter()` 判断 `guideSeen() && getLast() !== null` 后调用 `showWallDefault({ lastB })`，600ms 延迟后给 cell 添加 `last-visited` 类（避免与视图入场动效重叠），4s 后恢复默认展签。
- **5.6-5.7 沉浸页**：`focusFavBtn`（◇/◆）与 `focusTodayTag`（今日胶囊）并排于右上角，后者 `z-index` 与收藏按钮错开。`updateFocusFavBtn()` 切换类 + aria-label；`updateFocusName()` 重建 DOM（nameSpan + 可选 `.focus-name-fav ◆`）。
- **5.8 收藏角点**：`.cell.is-fav::after` 纯 CSS 3px 圆点，`::after` 需要父 `position:relative`（已在 `.view-grid .cell` / `.view-band .cell` 补上）。`refreshFavDots()` 遍历全部 cells 同步 class。
- **5.10-5.11 收藏展厅卡**：`favsCard` 独立于 `chapterCards`，`updateFavsCard()` 在收藏变化时按 favs 数组重建卡片内容（渐变条 / 标题 / 副文案）。`enterFavsChapter()` 设 `spotlightFavs = true`，`applySpotlight()` 据此判断哪些格子需要 `.dimmed`。
- **5.12 长按菜单**：`#focus-menu` 用 `position:fixed` 固定在底部，`menu-rise` 动效入场；长按 `focusPressTimer` 超时打开；菜单内按钮的 click 需 `e.stopPropagation()` 阻止冒泡到 `focus` 的 click-to-exit。
- **5.13 About 入口**：`aboutTodayBtn` 用 CSS 变量 `--today-bg` 给 `::before` 圆点上色，避免内联 SVG 或额外元素。
- **5.15 展厅日历**：逻辑挂在各章节卡的 `pointerdown` 长按计时器上（700ms）；计算逻辑复用 `todayB()` 的同款算法对本月每天求 b；色点 `.cal-dot.in-seg` 的 `background` 由 JS 内联设置，CSS 只做兜底。

## 技术要点

- **开屏光色动态注入**：用 `document.createElement('style')` 在 `<head>` 注入覆盖样式，比直接操作 CSS 变量更简洁，同时不污染全局样式表。
- **favs 上次停留的时序**：`enter()` 中上次停留提示需在 `renderView()` 之后（stage 已可见）且延迟 600ms（等待视图入场动效完成），避免与 stagger 动效产生视觉冲突。
- **收藏角点 ::after 的 position**：`::after` 定位需要父元素 `position:relative`；原有 `.cell` 只在 band/grid 视图有需求，故仅对 `.view-grid .cell` 和 `.view-band .cell` 补 relative，避免影响 ring 视图的 absolute 布局。
- **focusSuppressed 与菜单共存**：长按超时会设 `focusSuppressed = true`，阻止随后的 click 退出沉浸页；菜单按钮的 click 同样需要 `e.stopPropagation()` 否则会穿透到 `focus` 的 click handler。
- **展厅卡片长按与点击去冲突**：章节卡的长按 timer 在 `pointerup/cancel/leave` 时清除，不影响正常点击进入展厅。
