# fafa-color · 产品设计思路 (v0.1)

## 1. 灵感来源

朋友的名字是 **"fafa"**，它恰好是一个合法的十六进制颜色前缀。
当它作为一个 RGB 颜色出现时，介于：

- `#fafa00` —— 明亮的黄（R=250, G=250, B=0）
- `#fafaff` —— 近乎白的浅蓝（R=250, G=250, B=255）

也就是说，**"fafa" 不是一个颜色，而是一个颜色的区间**：
一个固定 R=FA、G=FA，蓝色通道 B 从 00 到 FF 渐变的空间，共 256 种颜色。

> 一个人的名字，可以不是一种颜色，而是一片颜色。

## 2. 核心概念

把"名字"转译成"颜色区间"，让访问者进入一片属于"fafa"的色彩之海：

- **fafa 空间** = R=0xFA, G=0xFA, B∈[0x00, 0xFF] 的所有颜色
- 从 `#fafa00`（黄）经 `#fafaa0`（浅青）到 `#fafaff`（近白），是一种"从热烈到纯净"的渐变叙事
- 这是一个人造的、有限的、可数的色彩宇宙（恰好 256 格）

## 3. 产品目标

| 目标 | 说明 |
| --- | --- |
| 艺术表达 | 将人名诗意地转译成可视化的色彩空间 |
| 互动体验 | 让访客在 256 个颜色中游走、发现、收藏 |
| 技术趣味 | 色彩、数学、极简前端美学的展示 |
| 情感承载 | 一种给朋友的、低成本但有深意的数字礼物 |

## 4. 页面结构（单页）

> 设计原则：**文字尽量隐身**。用色彩、几何、动效本身表达含义；
> 必须出现的文字以极低存在感呈现（小字号、低透明度、模糊滤镜、悬停/点击后才浮现）。

### 4.1 开屏：以光表达命名
- 全屏渲染缓慢色流动画，底色从 `#fafa00` 缓慢流向 `#fafaff`
- 不出现文字，用**色相呼吸 + 两个极值色点（黄 ⇄ 白）**暗示"这个人的区间"
- 中央以一块不断漂移、渐变的色块（可呈"f"字形轮廓光斑）代替任何文字
- 无"进入"按钮：任意触摸/点击/滚动即进入主场景

### 4.2 主场景：256 格色域
- 默认视图为 **256 色阶**，按 B 值 0→255 水平排布（可用一条细线或一行格子）
- 支持多种布局切换：
  - **一维色带**（经典水平光谱）
  - **16×16 网格**（按 B 高字节 / 低字节映射成矩阵，构成色板画布）
  - **环形色盘**（B 值作为极角，形成渐变圆环）
- 触摸/悬浮任一颜色时：
  - 颜色放大 1.2 倍 + 周围泛起微光
  - hex 值 `#fafaxx` 以小字号、低对比度浮现于手指/光标附近，稍后自动隐去
  - 颜色的诗意名字仅在对焦模式下显示（见 §6）

### 4.3 细节：单一颜色全屏
- 点击某个颜色进入全屏沉浸视图
- 该颜色缓慢呼吸（明度微幅波动）
- 不直接显示文字：以**色名首字组成的低透明度水印（blur 滤镜）**铺满背景
- hex 值仅在屏幕角落以 8px 等宽小字若隐若现
- 一句话文案不出现，改用颜色自身的明暗节奏讲故事（见 §6 注释）

### 4.4 彩蛋
- 双击同色 3 次（移动端为连点），触发"fafa 烟花"粒子效果，无色文字、纯粒子
- 屏幕边缘出现极淡的 "fafa" 光斑水印（blur + 低透明度），仅 2s 后消散

## 5. 交互设计

| 交互 | 描述 |
| --- | --- |
| 触摸/悬浮 | 颜色放大 1.2 倍 + 泛起微光，hex 值小字低对比度短暂浮现 |
| 点击 | 进入单色沉浸页 |
| 双指/滚轮 | 在一维 / 网格 / 环形视图间切换 |
| 长按 | 复制 `#fafaxx` 到剪贴板（复制成功以轻微色闪反馈，不弹文字） |
| 拖动 | 移动色块以自建 16×16 色板并导出 |

> **移动端兼容策略**
> - 无 hover：一律以 `touchstart/touchmove/touchend` 取代 hover
> - 支持 `touch-action`、`-webkit-tap-highlight-color: transparent`、`overscroll-behavior`
> - 全屏沉浸页适配横竖屏，用 `100dvh` 而非 `100vh`（规避移动端地址栏）
> - 所有文字元素预留 `@media (hover: none)` 隐藏/降级样式，触摸时才浮现
> - 触屏下禁用双击缩放，防止误触彩蛋

## 6. 颜色命名系统

为 256 个颜色生成诗意名字，规则：

- 按 B 值分 8 段，各配主题词（示例）：
  - B≈00：`黎明 · 柠檬 · 初醒`
  - B≈32：`午后 · 麦浪 · 微光`
  - B≈64：`海盐 · 薄雾 · 清浅`
  - B≈96：`风铃 · 春茶 · 静谧`
  - B≈128：`湖畔 · 云朵 · 悠远`
  - B≈160：`月光 · 棉絮 · 轻盈`
  - B≈192：`星夜 · 凝露 · 温柔`
  - B≈224：`雪原 · 极光 · 纯粹`
- 命名格式：`fafa 的<主题词>·#fafaxx`
- **呈现方式**：这些名字不直接做标题，而是以极低透明度的水印、或只在对焦模式（长按后）显示，默认保持隐形

## 7. 视觉与动效基调

- 底色：从 `#fafa00` 到 `#fafaff` 的柔和流动渐变
- 字体：等宽字体显示 hex 值（8px 小字、低对比度、blur 滤镜），日常状态下几乎不可见
- 动效：CSS 渐变 + 轻量 Canvas 粒子，避免重框架
- 呼吸感：全局色相在 60s 内做极缓慢的 B 值漂移（±8）
- 文字隐身法则：
  - 字号 ≤ 8px、透明度 ≤ 0.25、可叠加 `blur(1px)`
  - 仅在与内容交互（触摸/点击）时才浮现，2s 内自动隐去
  - 大段文字一律不用，改为色彩 / 光斑 / 粒子叙事

## 8. 技术方案

- **栈**：Vite + 原生 JS/TS + CSS（保持极简，无需框架）
- **色彩计算**：`#fafa00` 至 `#fafaff` 插值公式 `rgb(250, 250, b)`，b ∈ [0,255]
- **布局**：CSS Grid（16×16 与色带）+ Canvas（环形、粒子）
- **剪贴板**：`navigator.clipboard.writeText`
- **导出**：把 16×16 布局渲染到 `<canvas>` 后 `toDataURL` 下载 PNG
- **移动端**：媒体查询 `(hover: none)` 与 `(pointer: coarse)` 适配，`dvh` 视口单位
- **无后端**：纯静态部署
