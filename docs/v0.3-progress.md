## 实施日志

- **起**：v0.3-plan 文档落定，明确「不开门即亮黄」为首要问题。
- **3.1 完成**：`#splash` 拆为三层——底层 `#fafaff`、中层 radial 暖光晕、顶层 fafa 渐变条；`opacity` 与 `scale` 动画分开控制，首帧几乎无黄。
- **3.2 完成**：`#splash` 增加 `.fade-out` 类，点击后 0.6s 淡出；`#stage` 进入时 opacity + scale 双过渡。
- **3.3 完成**：`renderView()` 渲染时先给 `#view` 加 `entrancing no-transition`，设置每个 cell 的 `transition-delay`，再下一帧移除 class 触发 stagger。
- **3.4 完成**：新增 `ripple(x, y, color)` 辅助函数，在 view 与 focus 的 `pointerdown` 中调用；CSS `.ripple` 用 transform + opacity 扩散。
- **3.5 完成**：`#focus` 从 keyframe `focus-in 0.6s ease` 升级到 `0.55s cubic-bezier(0.22, 1, 0.36, 1)`，scale 从 1.06 回到 1。
- **3.6 完成**：`#fx-mark` 增加 `transform` 过渡，`.on` 时 opacity 0.15s 淡入 + transform 1.8s 呼吸。
- **3.7 完成**：`@media (prefers-reduced-motion: reduce)` 覆盖所有新元素，并显式设置 `#splash::after`、`#stage`、`#focus` 的静态可见值。
- **3.8 完成**：`showTooltip` 改为显示 `nameOf(b)`；`#tooltip` 增大内边距、最大宽度，并改为指针上方居中定位。
- **3.9 完成**：`enterFocus` 调用 `renderFocusName()` 默认展示名字；长按动作改为 `copyFocusName()` 仅复制 + 反馈；`#focus-name` 样式提升可读性但保持低对比度。
- **3.10 完成**：主场景 HTML 增加 `#stage-mark`；CSS 42vmin 大字、`rgba(250,250,0,0.035)`、`blur(10px)`、`pointer-events: none`、z-index 低于 `#view`。
- **3.11 完成**：主场景 HTML 增加 `#stage-tagline`；顶部居中 10px 细字、0.18 透明度、轻微模糊。
- **验证**：`npm run build` 通过，CSS 7.99 → 8.72 KB，JS 10.98 → 11.12 KB。

## 技术要点

- **开屏分层**：`#splash` 本身为 `#fafaff` 纯色；`::before` 负责 radial 暖光晕，`::after` 负责 fafa 渐变带；两者初始 opacity 为 0，避免首帧亮黄。
- **渐进 reveal**：`dawn-glow` 14s 循环让暖光从中心慢慢晕开；`dawn-reveal` 7s 内把渐变带从 0 提升到 0.38 透明度，随后接上 `splash-flow` 缓慢流动。
- **stagger 实现**：利用 `view.entrancing .cell { opacity: 0.35 }` + `view.no-transition .cell { transition: none }` + 每 cell `transition-delay`，在 `requestAnimationFrame` 中移除 entrancing 触发批量淡入。
- **涟漪性能**：DOM 元素 + CSS transform/opacity，无 layout，每点击产生一个元素并在 760ms 后移除。
- **彩蛋水印呼吸**：`#fx-mark.on` 时 transform 过渡时长 1.8s，与 opacity 的 0.15s 解耦，实现先显影后呼吸。
- **颜色名显性化**：`nameOf(b)` 复用 v0.2 命名库；tooltip 与 focus-name 均显示 `fafa的<主题词>·#fafaxx`，以「fafa」前缀统一主题；长按复制行为与默认展示分离，避免信息闪烁。
- **氛围文字层级**：`#stage-mark` z-index 1 置于 `#view` (z-index 2) 之下，确保不遮挡色块；`#stage-tagline` z-index 3 置于顶部，但 pointer-events: none。
