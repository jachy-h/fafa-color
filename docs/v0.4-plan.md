# fafa-color · v0.4 设计思路（数字画廊版）

> 起点：v0.3 完成了开屏拂晓化与全链路动效叙事，文字刻意保持在「氛围」层级——极低透明度、模糊、小字号。
> 本版本做两件事：①「略微提高文字存在感」（本次已先行落地，见 §0.1）；② 参照当代艺术类网站的通行做法，把站点升级为一座「256 色的数字画廊」——让名字从氛围走向可读，让颜色依然是唯一的主角。

## 0. 网络调研：当代艺术类网站长什么样

调研对象：Awwwards 获奖站点与趋势文章、MoMA（现代艺术博物馆）、Artsy（全球最大在线艺术市场）、Are.na（创意收集平台）及其 Design 文章。

| 来源 | 观察到的手法 | 对 fafa 的启发 |
| --- | --- | --- |
| Awwwards / 获奖作品 | 版式是身份：自定义字体、Variable Font、超大字形；渐变被用在 hover、标题、图标等次要元素；One-page / 滚动叙事；微渐变 + 模糊 + 光晕 | 给中文名配一套展示级衬线字族；把「fafa」色域做成持续流动的氛围渐变，而非只在开屏 |
| MoMA | 作品优先、标签退后：每一件作品只配一行「艺术家 · 标题 · 年代」的小字展签；大量留白；策展式叙事（展览 / 馆藏 / 活动分层） | 引入「展签（Wall Label）」：每个色块旁只有一行名字，章节即展厅 |
| Artsy | 编辑化叙事：策展人推荐、收藏（heart）、「找到打动你的作品」的情绪文案；画廊 / 展览 / 艺术家三层信息架构 | 沉浸页像「作品页」：名字即标题、hex 即编号、章节即展厅；增加收藏 |
| Are.na | 品牌字体即身份（自研 Areal 字体）；拒绝广告、拒绝算法推荐；宣言式的克制文案「Creativity is just connecting things」；开放 API | 增加「策展词」入口：无算法、无广告、256 个名字靠人工命名；站点的价值观被写出来 |

### 0.1 本次已先行落地的「文字存在感」微调（任务一）

| 元素 | 改动 |
| --- | --- |
| `#stage-mark` fafa 水印 | 颜色 `0.035 → 0.08`，blur `10px → 6px` |
| `#stage-tagline` 顶部文案 | `10px → 11px`，透明度 `0.18 → 0.34`，去掉模糊 |
| `#tooltip` 悬浮提示 | `9px → 10px`，文字 `0.42 → 0.6`，底色 `0.6 → 0.78` |
| `#focus-hex` 右下 hex | `8px → 9px`，`0.24 → 0.42`，呼吸下限 `0.05 → 0.12` |
| `#focus-name` 左下色名 | `11px → 12px`，`0.48 → 0.68`，去掉 blur |
| `.focus-mark` 沉浸页大字 | `0.06 → 0.12`，blur `9px → 6px` |
| `.glyph` 开屏 fa 字形 | `0.04 → 0.08`（呼吸峰值 `0.11 → 0.17`），blur `9px → 6px` |

> 原则：只提升「可读性」，不改变「颜色是主角」的层级。所有文字仍显著低于色块的视觉权重。

## 1. 目标

| 目标 | 说明 |
| --- | --- |
| 站点赞同画廊 | 让访问者第一眼就明白：「这里是 256 个有名字的颜色的展馆」 |
| 展签化文字 | 用「博物馆展签」的语法承载名字与编号，文字存在感适中、艺术感十足 |
| 策展式导航 | 8 个色段 = 8 个展厅，可像看地图一样浏览与跳转 |
| 作品页化沉浸页 | 沉浸页从「一屏颜色」升级为「一幅作品的展厅页」 |
| 保持克制 | 零新依赖、CSS 优先、颜色仍是主角、动效可被感知但不吵闹 |

## 2. 范围

### 2.1 展签系统（Wall Label）⭐ 核心

> 借鉴 MoMA：作品 + 一行小字展签。让名字常驻、可读，但不抢戏。

- **常驻展签**：主场景左下角新增 `#wall-label`（与 `#focus-name` 同侧同构，形成「一个站点两处展签」的呼应）。
  - 常态：`第 1 展厅 · 黎明 · 柠檬 · 初醒`（当前/最后交互的色段），下附一行细字 `#fafa00 – #fafaff · 共 256 色`。
  - 交互态：hover / 触摸某个 cell 时，第一行变为 `fafa的柠檬 · #fafa00`，第二行保持展厅信息；移开后回退为常态。
- **样式**：仿展签板——上方 1px 细线分隔，9–10px，中文用衬线、hex 用等宽，对比度约 0.55（比 v0.3 的 tooltip 更克制、更「馆方」）。
- **与 tooltip 的关系**：tooltip 保留为「跟随指针的即时提示」（短促、临时）；展签是「常驻的状态标签」。二者各司其职，避免重复。
- **移动端**：展签缩至 8–9px，单行优先，超长省略。

### 2.2 章节化展示：8 个展厅（Chapters）

> 借鉴 Artsy / MoMA 的策展式分层：色段即展厅，每个展厅有自己的名字、导览语与色域。

- **新增第 4 个视图 `chapters`（展厅地图）**：band → grid → ring → chapters → band 循环，底部指示点变为 4 个。
- **展厅卡片**（每展厅一张，2 列网格 / 移动端竖排）：
  - 顶部：该展厅 32 色的横向渐变条（当作「画作预览」）。
  - 标题：三个词的展示级衬线字（如 `海盐 · 薄雾 · 清浅`）。
  - 导览语：一句策展文案（§4 文案库）。
  - 编号：`Room 03 · #fafaa0 – #fafabf`。
- **跳转**：点击卡片进入 grid 视图并打开「展厅聚光」——该展厅的 32 格保持全亮，其余格子降至 0.15 透明度；角落出现「只看此展厅 ×」chip，点击恢复全部。再次循环到 chapters 可切换展厅。
- **实现**：chapters 视图内允许纵向滚动（其余视图仍全屏锁定）；聚光用 JS 给非展厅 cell 加 `.dimmed` 类（CSS 0.15 opacity + 轻微去饱和），256 格性能无虞。

### 2.3 字体与版式（文字存在感的结构性升级）

> 借鉴 Awwwards 的「版式即身份」与 Are.na 的品牌字体。

- **展示衬线字族**：为展厅标题、沉浸页色名、展签中文引入
  `"Songti SC", "STSong", "Noto Serif CJK SC", "Noto Serif SC", serif`；
  hex 与编号继续用 `ui-monospace`。同一行内「衬线中文 + 等宽 hex」本身就是画廊展签的视觉语法。
- **tagline 升级**：`一个人的名字，一片颜色` 由顶部移动至开屏主画面下方，字号提升至 14px 细体（保留低对比），作为「入场宣言」；主场景内仍保留顶部小字。
- **沉浸页色名**：放大至 20px 衬线细体作为「作品标题」，hex 缩为 9px 作为「编号」，二者分列左右下角。

### 2.4 沉浸页升级为「作品页」

> 借鉴 MoMA 作品页 / Artsy 收藏。

- **信息结构**：中央是颜色本体（不变）；左下 `作品标题`（色名，衬线）；右下 `编号 · 展厅`（`#fafaff · 第 8 展厅`）。
- **展厅内导航**：沉浸页左右滑动（或双指/方向键）在同展厅 32 色内切换上一件/下一件「作品」，颜色间平滑过渡（crossfade 0.25s）。
- **收藏（P1，可选）**：右上角一个「☆ 收藏」按钮，写入 `localStorage`（key `fafa:favs`，存 b 数组）；在展厅地图/关于页提供「我的收藏」列表（色条 + 色名 + hex，点击进入）。若本版本不做，延后至 v0.5。

### 2.5 策展词与参观指南（About）

> 借鉴 Are.na 的宣言式文案与 MoMA 的「参观指南」。

- 主场景左上角新增「i」按钮，打开全屏 overlay（复用 focus 的入场动效）：
  - **策展词**：「这里没有别的颜色。只有 256 个名字，和它们各自的 fafa。每一种颜色都是一个人的名字，每一个名字都代表一片颜色。」（§4）
  - **如何参观**：点击进入颜色 · 长按复制名字 · 滚轮/滑动切换视图 · 三击燃放烟火 · 双指切换。
  - **展厅目录**：8 个展厅的名称 + 导览语 + 色域，点击直达展厅聚光。
- overlay 内容可滚动，`prefers-reduced-motion` 下无动画。

### 2.6 渐变氛围（微交互的「画廊感」）

> 借鉴 Awwwards 渐变趋势：渐变用于次要元素而非主角。

- **hover/active 光晕**：cell 激活时不只做 `scale + 提亮`，改为一层取自当前色段的双色渐变光晕（用单个全屏 overlay 元素按触点定位，避免 256 个 box-shadow 造成性能压力）。
- **沉浸页氛围光**：`.focus-glow` 由单色 radial 升级为 `segmentPalette(seg)` 采样出的多色径向渐变，缓慢漂移，让每间「展厅」有自己的光色。
- **开屏渐变带**：沿用现有 `dawn-*`，仅在 v0.4 把流速与相位调至与展厅氛围一致，不做结构性改动。

### 2.7 动效补充（与 v0.3 叙事一致）

- 展签出现/更新：0.2s 淡入淡出，内容变化时轻微上移。
- chapters 视图卡片：stagger 入场 + 顶部色条从左到右「流淌」显现。
- 展厅聚光打开/关闭：0.35s ease，非展厅格子渐变到 dimmed。
- 所有新动效在 `prefers-reduced-motion` 下禁用。

## 3. 技术约束

- **零新依赖**：继续 Vite + 原生 JS + CSS。
- **CSS 优先**：渐变、stagger、聚光用 CSS class + transition；JS 只负责类切换与数据。
- **不破坏 v0.1–v0.3**：开屏、命名、导出、彩蛋、三连击、长按复制全部保留。
- **性能**：256 cell 只做 opacity/transform/filter 过渡；hover 光晕用单个 overlay；localStorage 读写量极小。
- **无障碍**：`prefers-reduced-motion` 覆盖全部新动效；展签/按钮均有 `aria-label`；overlay 可关闭、可滚动。
- **构建**：`npm run build` 通过，bundle 增量控制在 +6 KB 以内（gzip）。

> 这里没有别的颜色。只有 256 个名字，和它们各自的 fafa。

## 7. 非范围（明确不做）

- 不做多语言 / 自定义命名（延后至 v0.5）
- 不做暗色模式 / 主题切换
- 不引入 WebGL / Three.js / 外部字体加载（衬线字族全部走系统字栈）
- 不做音效、不做后端、不做账号系统
- 开屏与彩蛋物理不重构，仅参数微调
