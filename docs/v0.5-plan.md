# fafa-color · v0.5 设计方案

> 起点：v0.4 完成了「数字画廊」的完整基建——展签、展厅、作品页、引导动画、策展词。256 个颜色已经有了名字、展厅和灯光。
> 本版本回答一个问题：**在颜色已经「被命名」之后，它还能「被记住」「被感受」「被关系到人」吗？**

---

## 一、诊断：当前版本的三个未竟之处

| 维度 | 当前状态 | 未竟的感受 |
| --- | --- | --- |
| **艺术** | 颜色是静态的画布。256 格安静地待在那里，等人来看。 | 缺少时间性：颜色与访问这件事之间，没有「正在发生」的感觉 |
| **交互** | 单向消费。用户浏览、点击、长按，但从未「留下什么」。 | 缺少痕迹：这次访问与下次访问之间，没有积累 |
| **故事** | 「一个人的名字，一片颜色」已经点题，但故事停在了「命名」。 | 缺少第二章：名字被命名之后，然后呢？有人看见吗？有人停留吗？ |

---

## 二、v0.5 的核心主张

> **「颜色不只是被看的，是被遇见的。」**

每一种颜色，都在等待它「被某个人」停留的那一刻。  
v0.5 要把这件事变成可见的、可感受的、可积累的。

三个子命题：
1. **收藏** — 我看见了这种颜色，我想把它带走。（个人与颜色的关系）
2. **时序** — 颜色是有温度的，今天的颜色和昨天的颜色不同。（颜色与时间的关系）
3. **呼吸** — 这个画廊在等我，它知道我来过。（颜色与人的关系）

---

## 三、设计方案

### 3.1 收藏系统：「我的颜色」⭐ 核心功能

> **核心意象**：美术馆里的「语音导览」——有人在某幅作品前停留了更久。

#### 3.1.1 收藏行为

- 在**沉浸页（focus）** 右上角增加一个收藏按钮：`◇`（未收藏）→ `◆`（已收藏）。
- 样式：12px 等宽字，透明度 0.45，无边框，不抢戏；点击时有 0.3s 的轻微放大+亮度闪烁反馈。
- 写入 `localStorage['fafa:favs']`（存 b 值数组，最多 32 个）。
- 长按（550ms）沉浸页底部色名 → 弹出「收藏 / 已收藏」提示（与复制并列）。

#### 3.1.2 「我的收藏」展厅

- `chapters` 视图最后追加一张特殊卡片：**「我的收藏」**。
  - 卡片顶部渐变条：实时从 `favs` 数组取色，若空则显示一条细线（「还没有收藏的颜色」）。
  - 标题：`我看见的颜色`（衬线）。
  - 副文案：`第 N 种 · 等你发现`，空时 `还没有 · 随时可以收藏`。
- 点击卡片 → 进入 grid 视图，**聚光收藏的色格**（仅亮显 favs 里的 b，其余 dimmed）。
- 聚光 chip 改为 `只看我的收藏 · 全部`。
- 若 favs 为空，点击后进入 grid 全显（不聚光），chip 不出现。

#### 3.1.3 收藏的存在感

- 主场景底部的 wall-label 常态文案增加一个微小提示：若有收藏，常态文案变为 `256 种颜色 · N 种已收藏`。
- 在沉浸页内，若当前颜色已被收藏，`#focus-name`（左下色名）旁显示一个 `◆`（不另起行，同行尾部，透明度 0.35）。

---

### 3.2 「今日之色」：颜色与时间的关系 ⭐ 艺术性最强

> **核心意象**：日历——每一天有属于它的一种颜色。

#### 3.2.1 算法

```
b = (dayOfYear + yearSeed) % 256
```

`dayOfYear`（0-365）+ `yearSeed`（年份 % 256），每天得到一个确定的 b 值，对应一种 fafa 色。

- 确定性：同一天所有访问者看到同一种颜色，有「共同今日」的感觉。
- 全年覆盖：365 天不重复（256 色会重复，但轮回本身就是诗意）。

#### 3.2.2 呈现

**方案 A（克制）：开屏拂晓光的颜色**
- 开屏的 `dawn-glow` 暖色光，由固定的暖黄色改为**今日之色**的 rgba。
- 若今日之色是偏白的（b > 200），光晕做相应的蓝白调。
- 效果：每天进来，开屏感觉「今天和昨天有点不一样」，但说不清哪里不同——正是这种微妙最诗意。

**方案 B（明显）：wall-label 常态文案**
- 在 wall-label 常态的下方，追加第三行极细文字：`今天是 fafa的×× · #fafaXX`，字号 8px，透明度 0.28。

**两个方案都做**，A 是感官体验，B 是可被读懂的注脚。

#### 3.2.3 「今日之色」的沉浸入口

- About 页（策展词下方）新增一个入口：`→ 今天是哪种颜色`，点击直接进入今日颜色的沉浸页。
- 沉浸页内，若当前颜色恰好是今日之色，右上角（与收藏按钮并列）显示 `今日` 标签（8px 等宽，淡显）。

---

### 3.3 留白的诗意：「你上次在这里」

> **核心意象**：美术馆的「上次访问」印章——不是通知，是一种安静的被记住。

#### 3.3.1 行为

- 每次用户进入沉浸页，记录最后停留的颜色 b 值到 `localStorage['fafa:last']`。
- 再次打开网站，**如果不是首次访问**（guide 已看过），开屏后进入主场景的瞬间：

  wall-label 的默认文案**临时**变为：
  > `上次你停在了 fafa的×× · #fafaXX`
  
  4 秒后淡出，恢复为正常默认文案。

- 若从未进入过沉浸页，则不显示。
- 该文案是**单向的、无声的**——它不要求用户回应，只是轻轻说一句「我记得」。

#### 3.3.2 主场景的「上次停留」高亮

- 进入主场景时，如果有 `fafa:last` 记录，对应的 cell **短暂亮显**（1.5s 的 scale 1.05 + 轻微光晕），随后恢复正常。
- 无 chip、无提示文字，动效本身即是全部信息。

---

### 3.4 彩蛋进化：「展厅日历」🗓️

> 奖励深度探索者的隐藏彩蛋。

- 在 chapters 视图，**长按某张展厅卡片**（700ms）→ 弹出该展厅的「本月情况」：
  - 本月第几天属于该展厅（基于「今日之色」算法）。
  - 「这个月，黎明来了 N 次。」
  - 以微型日历网格展示（5×7，当月每日的今日之色，色格小圆点）。
- 样式：像一张老式日历撕页，浅色背景，小字，1.5s 后自动消失（或点击关闭）。
- 意义：让访问者感受到「颜色是有季节的」。

---

### 3.5 交互细节优化

#### 3.5.1 收藏与长按的手势分层（重新梳理）

| 手势 | 当前行为 | v0.5 新行为 |
| --- | --- | --- |
| 点击 cell | 进入沉浸页 | 不变 |
| 长按 cell | 复制 hex | 不变 |
| 沉浸页 点击 | 退出 | 不变 |
| 沉浸页 长按 | 复制 hex | 改为弹出操作菜单：`复制 hex · 收藏 · 取消收藏` |
| 沉浸页 右上角 ◇ | — | 切换收藏状态 |

#### 3.5.2 Ring 视图的今日之色标记

- 在 ring 视图中，今日之色的 cell 有一个**极淡的光晕圆圈**（`box-shadow: 0 0 8px 2px currentColor, opacity 0.3`），使其在圆环上被隐约分辨。
- 不出现任何文字，只是光。

#### 3.5.3 Grid 视图的收藏标记

- 已收藏的 cell，在 grid 视图中有一个**角点微标**：右上角 1×1 px 的白色圆点（opacity 0.6），极小，只在仔细观察时可见。
- 美学：不是图标，是一个微小的「印记」，像博物馆展品的收藏标签。

## 五、技术约束

- **零新依赖**：全部用原生 JS + CSS，无库。
- **localStorage 键**：`fafa:favs`（b 数组，JSON），`fafa:last`（单个 b 值），`fafa:guide:v1`（已有）。
- **favs 上限**：32 个（一间展厅的容量），超出时弹出轻提示「收藏已满，移除一个再试」。
- **今日之色算法**：纯客户端，无服务端依赖，确定性由日期决定。
- **新增文件**：`src/favs.js`（收藏读写 + 聚光逻辑），`src/today.js`（今日之色算法 + 相关渲染）。
- **CSS 增量**：估计 +3 KB（未压缩），gzip 增量 < 1 KB。
- **性能**：grid 视图收藏角点用 `::after` 伪元素 + CSS class，不新增 DOM。

## 六、范围边界

### 纳入

| 功能 | 优先级 |
| --- | --- |
| 收藏系统（沉浸页 ◇、收藏展厅卡、grid 角点、wall-label 提示） | P0 |
| 今日之色（开屏光色、wall-label 第三行、About 入口、沉浸页标记） | P0 |
| 上次停留（wall-label 临时文案、cell 短暂亮显） | P1 |
| Ring 视图今日之色光晕 | P1 |
| 展厅日历彩蛋（长按章节卡） | P2 |
| 沉浸页长按操作菜单 | P1 |

### 不纳入

- 多语言 / 自定义命名（延后 v0.6）
- 社交分享功能（无服务端，暂不做）
- PWA / 离线缓存（v0.6）
- 音效
- WebGL / 外部字体
