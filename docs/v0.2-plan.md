# fafa-color · v0.2 设计思路

> 起点：v0.1 已完成 256 色带 + 16×16 网格 + 环形色盘 + 单色沉浸 + 剪贴板复制 + 移动端适配。
> 本版本聚焦「给颜色以名字」「把颜色带出去」「留一颗彩蛋」三件事。

## 1. 目标

| 目标 | 说明 |
| --- | --- |
| 命名 | 让 256 个颜色拥有可读、可复制、可被记住的诗意名字 |
| 沉浸深化 | 沉浸页用名字讲故事，并保留「文字隐身」原则 |
| 分享 | 把 16×16 网格色板一键导出成 PNG，便携分享 |
| 彩蛋 | 给高频用户一个惊喜：双击同色 3 次触发烟花 |

## 2. 范围

### 2.1 颜色命名系统（命名库）

- **8 段主题词**（参考 v0.1 §6，按 B 值均分 8 段，每段 32 色）：
  - B∈[0,32)：`黎明 · 柠檬 · 初醒`
  - B∈[32,64)：`午后 · 麦浪 · 微光`
  - B∈[64,96)：`海盐 · 薄雾 · 清浅`
  - B∈[96,128)：`风铃 · 春茶 · 静谧`
  - B∈[128,160)：`湖畔 · 云朵 · 悠远`
  - B∈[160,192)：`月光 · 棉絮 · 轻盈`
  - B∈[192,224)：`星夜 · 凝露 · 温柔`
  - B∈[224,256)：`雪原 · 极光 · 纯粹`
- **命名格式**：`fafa的<词>·#fafaxx`（主题词按段内位置确定性选择，避免每渲染都随机）
- **决定性映射**：每段用 32 个 B 值在该段的 3 个主题词中循环，保证同一 B 值始终得到同一名字
- **数据形态**：纯函数 `nameOf(b: number) => string`，无副作用、可外部调用

### 2.2 沉浸页命名展示与水印

- 默认仍「文字隐身」：沉浸页**不显示**命名名字
- 长按 700ms：颜色名以 12px 等宽小字、低对比度、blur(1px) 出现在 hex 旁
- 5s 内自动隐去
- 背景水印：当前颜色名首字「雨打梨花」式排成网格，blur(2px) + opacity 0.05+repeat
- 移动端：长按 1100ms（容错更宽），且首次进入用侧滑返回手势（`swipe right` ≥ 60px）退出沉浸页

### 2.3 色板导出 PNG

- 在 16×16 网格视图下，**主场景右上角**（移动端右下角）出现一个极淡的「↓」导出符号
- 触发：
  - 桌面：点击导出
  - 移动端：长按 600ms 导出（避与色块长按冲突：仅在网格视图 + 触发指针不命中 `.cell` 时启用）
- 渲染：临时 `<canvas>`（1080×1080 或按 16×16 实际像素）每个 cell 填充 `rgb(250,250,b)`，0 间隙
- 文件名：`fafa-palette-{timestamp}.png`
- 反馈：导出成功后全屏 0.6s 的极淡白色 flash，不弹任何文字

### 2.4 粒子彩蛋（fafa 烟花）

- 触发：双击同色 3 次（连续 3 次双击的目标 B 值相同）
- 时间窗：6s 内累计 3 次；超时则计数清零
- 效果：
  - 从被点击的色块位置喷出 60~120 粒子
  - 粒子颜色为「fafa 命名段」对应主题色调色板（每段各 5 色，共 40 色随机）
  - 粒子受重力 + 空气阻力，存活 1.4s
  - 屏幕边缘浮现极淡的「fafa」光斑水印（blur 12px + opacity 0.18），2s 后消散
- 实现：纯 Canvas 2D，覆盖在所有 view 之上，独立 `#fx` 层
- 移动端：300ms 内两次 `pointerdown` 视为双击
- 无障碍：`prefers-reduced-motion` 直接禁用彩蛋，改为一次轻微色闪

## 3. 技术约束

- **零新依赖**：沿用 Vite + 原生 JS + CSS
- **代码分层**：命名库 `src/name.js`、粒子 `src/fx.js`、导出 `src/exporter.js`；主文件 `main.js` 引入
- **不破坏 v0.1**：所有现有交互、单色沉浸、视图切换、移动端适配行为保持
- **构建**：保持 `vite build` 通过，bundle 增量 ≤ 6KB
- **完全静态**：无后端、无网络请求

## 4. 验收清单

- [ ] 每个 B 值都拥有一个稳定的名字（运行 `nameOf` 256 次结果确定）
- [ ] 沉浸页长按能看到名字并能复制
- [ ] 16×16 网格可导出 PNG，文件名带时间戳
- [ ] 同色双击 3 次触发烟花
- [ ] `prefers-reduced-motion` 下彩蛋退化为色闪
- [ ] `npm run build` 通过
- [ ] 移动端：色板导出入口可见可触；双击同色 3 次可触发；沉浸页可侧滑退出

## 5. 非范围（明确不做）

- 不做账号系统、配色收藏后端
- 不做 PWA / 离线缓存
- 不做多语言命名（仅中文）
- 不做"画板自由拖拽"功能（v0.1 计划里的，但本版本不重启）
- 不改主页信息架构（仍是单页 + 沉浸页）

## 6. 与原计划的对应

| v0.1 计划版本 | 原内容 | v0.1 实际已做 | v0.2 实际在做 |
| --- | --- | --- | --- |
| v0.2 | 16×16 网格 + 沉浸页 + 复制 | 已并入 v0.1 | — |
| v0.3 | 命名 + 文案库 | 仅占位 | **2.1 + 2.2** |
| v0.4 | 粒子彩蛋 + 导出 PNG + 动效打磨 | 仅基础动效 | **2.3 + 2.4** |

> 总结：v0.2 = 「命名 + 沉浸深化 + 导出 + 彩蛋」四件套，把 v0.1 计划里剩下的可交付体验全部补齐。
