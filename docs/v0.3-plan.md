# fafa-color · v0.3 设计思路

> 起点：v0.2 已完成命名系统、沉浸页文案、PNG 导出、粒子彩蛋。
> 本版本聚焦「第一印象修复」与「全链路动效叙事」：让开屏不再是一整块刺眼的亮黄，而是像黎明一样把颜色慢慢请进来；同时给每个视图切换、每次触碰、每次进入沉浸都配上细腻但不吵闹的动画。

## 1. 目标

| 目标 | 说明 |
| --- | --- |
| 开屏柔和化 | 解决「一打开就是满屏亮黄 #fafa00」的突兀感，改为从近白/低饱和逐渐过渡到 fafa 色域 |
| 动效叙事 | 用动画本身讲述「从热烈到纯净」的色彩故事，减少文字说明 |
| 视图转场 | band / grid / ring 切换时不再是硬切，而是有统一的过渡语言 |
| 微交互 | 触碰、复制、导出、彩蛋都有可被感知但不打扰的反馈 |
| 性能保持 | 不引入新依赖，CSS 动画为主，Canvas 仅用于彩蛋，持续 60fps |

## 2. 范围

### 2.1 开屏重设计：拂晓（Dawn）

#### 问题
当前 `#splash` 直接以 `linear-gradient(90deg, #fafa00, #fafaa0, #fafaff)` 铺满全屏，首帧就是高饱和亮黄，视觉冲击过强，与后续「从热烈到纯净」的叙事顺序相反。

#### 设计
- **色彩时序**：开屏首帧不是黄，而是 `#fafaff` 附近（几乎白），随后像一个缓慢的日出，黄色从画面中心/边缘一点点渗入，最终才让整个 fafa 区间完整流过。
- **实现**：使用多层背景 + `opacity`/`background-position` 动画。
  - 底层：`#fafaff` 纯色，始终稳定。
  - 中层：一个从中心向外扩散的暖色光晕（低饱和黄 → 透明），模拟太阳刚升起的辉光。
  - 顶层：fafa 区间渐变条，初始透明度极低，6s 内慢慢显现并缓慢流动。
- **中央光斑**：保留 `.blob`，但初始更小、更白、更模糊；12s 内慢慢长大并轻微变暖，像晨雾被阳光染上色。
- **字形**：`.glyph` 的 `fa` 初始透明度更低（0.04），并加入「从模糊到更模糊再到可读」的呼吸，避免一出现就抢戏。
- **进入方式**：保持任意点击/触摸进入，但进入时增加 0.6s 的淡出叠化，而不是当前的 `hidden` 硬切。

#### 动画清单
| 元素 | 动画 | 时长 | 说明 |
| --- | --- | --- | --- |
| 底层 | 静态 | — | 提供稳定锚点 |
| 暖色光晕 | `dawn-glow` | 14s | 中心 0% → 扩散 70%，透明度 0 → 0.45 → 0.25 |
| 渐变条 | `dawn-reveal` + `splash-flow` | 6s reveal + 14s flow | 先淡入，再缓慢流动 |
| 光斑 | `blob-dawn` | 16s | 从 0.7 scale 长到 1.18，颜色从白偏暖 |
| 字形 | `glyph-dawn` | 12s | opacity 0.04 → 0.10 → 0.06 呼吸 |

### 2.2 全局动效系统

#### 2.2.1 视图切换过渡
当前切换视图时，cell 只是瞬间重排。v0.3 要求：
- 切换前先给当前视图加一个 180ms 的「收拢」：所有 cell 轻微缩小、透明度降至 0.6。
- 新视图进入时做「绽放」：cell 从 0.85 scale 回到 1，透明度回到 1，并带轻微随机延迟（stagger）。
- 环形色盘额外增加旋转进入：从 `rotate(-15deg)` 到最终角度。

#### 2.2.2 Cell 入场 stagger
- band：从左到右依次淡入，延迟 = `b * 1.5ms`（256 个约 380ms 总时长）。
- grid：按行优先涟漪，延迟 = `(row + col) * 8ms`。
- ring：按角度顺序依次出现，延迟 = `b * 1.2ms`，并带 radial 缩放。

#### 2.2.3 环境呼吸
- 主场景 `#stage` 保留全局 `global-breathe`，但把 60s 周期拆成两段：
  - 前 30s：整体轻微变暖（叠一层极淡的黄）。
  - 后 30s：整体轻微变冷（叠一层极淡的蓝）。
- 让色域的「呼吸」可被潜意识感知，但不改变 cell 本身颜色。

### 2.3 微交互增强

#### 2.3.1 触碰涟漪（Ripple）
- 在 `#stage` 上叠加一个全屏 pointer-events-none 的 canvas 或纯 DOM ripple 层。
- 每次 `pointerdown` 在接触点产生一个扩散圆环：颜色取自当前 cell 的互补色或高亮白，1s 内放大并淡出。
- 移动端尤其需要，因为它替代了 hover 的视觉反馈。

#### 2.3.2 Tooltip 出现/消失
- 当前 tooltip 是硬显隐。
- v0.3：tooltip 从 scale 0.9 + opacity 0 到 scale 1 + opacity 1，持续 180ms；消失时反向 220ms。
- tooltip 位置增加轻微跟随延迟（用 rAF 插值），让光标移动时有「拖尾」感。

#### 2.3.3 复制反馈
- 当前 `.cell.copied` 只做亮度脉冲。
- v0.3：增加一个从 cell 中心向四周扩散的细小白环，0.5s 内淡出，让复制成功有一瞬间的「涟漪确认」。

#### 2.3.4 沉浸页进入/退出
- 进入：从 cell 的屏幕位置做 FLIP 动画到全屏，0.5s ease。
- 退出：反向 FLIP 回到 cell 位置，0.4s ease。
- 如果无法取得 cell 位置（如通过其他入口），则退化为中心放大/缩小。
### 2.4 导出反馈

- 导出按钮被触发时，按钮本身做 0.15s 的 scale 0.85 → 1 弹跳。
- 全屏 flash 改为从点击位置扩散的白色圆形遮罩，而不是整个屏幕统一变白，0.7s 内淡出。

### 2.5 颜色名的显性化呈现（FAFA 主题）

> 目标：让访问者意识到每一个色块都是一个以「fafa」开头的诗意命名，强化「名字即颜色宇宙」的艺术主题。

#### 2.5.1 悬浮/触摸提示
- tooltip 不再只显示 `#fafaxx`，而是显示完整命名：`fafa的黎明·#fafa00`。
- 样式保持低对比度、小字号、blur 背景，但适当增加内边距与最大宽度，确保中文名可读。
- tooltip 位置改为指针上方居中，避免长文本贴边。

#### 2.5.2 沉浸页默认展示
- 进入单色沉浸页后，颜色名直接出现在左下角，无需长按即可看到。
- 名字以 11px 等宽小字、半透明磨砂背景呈现，filter 轻微模糊但保证可读。
- 长按仍然保留「复制名字」的功能，复制成功以色闪反馈。
- hex 值继续放在右下角，与名字形成左下/右下的平衡构图。

#### 2.5.3 设计原则
- 文字不再完全隐身，而是像展品标签一样「低调存在」。
- 所有名字统一以 `fafa的` 开头，配合 hex 中的 `#fafa`，反复强调主题。
- 保持整体留白，避免名字成为视觉中心——颜色本身仍是主角。
### 2.6 彩蛋动效升级

- 粒子烟花保留现有物理，但增加：
  - 粒子颜色从 segment palette 中顺序选取，形成小范围色带。
  - 爆炸中心先有 0.1s 的「收缩」再喷发，增强爆发力。
- `fafa` 水印出现时带轻微 scale 0.96 → 1.04 呼吸，2s 内完成。

### 2.7 主场景氛围文字

> 目标：在主场景加入极低存在感的文字，作为艺术品签名与情绪提示，但不破坏「颜色是主角」的原则。

#### 2.7.1 「fafa」大字水印
- 在 `#view` 背后放置一个 42vmin 的「fafa」字形。
- 颜色使用极低透明度的暖黄 `rgba(250, 250, 0, 0.035)`，配合 `blur(10px)`，几乎与背景融为一体。
- 14s 呼吸动画：轻微 opacity 与 scale 波动，像一道淡淡的光斑签名。
- `pointer-events: none`，绝不阻挡色块交互。

#### 2.7.2 顶部 tagline
- 顶部居中放置一句短文案：`一个人的名字，一片颜色`。
- 10px 细字、0.18 透明度、0.4px 轻微模糊、0.2em 字间距。
- 作为展览标签式的存在，远看像一行浅浅的说明，近看可读。

#### 2.7.3 设计原则
- 文字是「氛围」而非「内容」：字号小、透明度低、带模糊，永远低于颜色层级。
- 所有氛围文字都置于 `#view` 的 z-index 之下或之上但不遮挡色块。
- 移动端同样保持纤细，不占用安全区。

## 3. 技术约束

- **零新依赖**：继续 Vite + 原生 JS + CSS。
- **CSS 优先**：stagger、淡入淡出、FLIP 过渡尽量用 CSS animation/transition；JS 只负责添加/移除 class。
- **不破坏 v0.2**：所有现有交互、命名、导出、彩蛋逻辑保持。
- **构建**：`npm run build` 通过，bundle 增量 ≤ 4KB。
- **无障碍**：`prefers-reduced-motion` 下所有新动效禁用，仅保留必要的状态切换。

## 4. 文件结构变化

├── main.js       # 新增 FLIP、stagger、ripple 调度

- [ ] 开屏点击/触摸进入主场景时有 0.6s 淡出叠化
- [ ] band / grid / ring 切换时有 180ms 收拢 + stagger 绽放
- [ ] pointerdown 产生颜色涟漪，移动端可感知
- [ ] 复制成功时 cell 有额外白环扩散反馈
- [ ] 沉浸页进出有 FLIP 过渡（若 cell 在视口内）
- [ ] tooltip 显示完整颜色名 `fafa的××·#fafa××`
- [ ] 沉浸页默认显示颜色名，无需长按
- [ ] 主场景有极低存在感的「fafa」大字水印与 tagline

- [ ] `npm run build` 通过

## 6. 非范围（明确不做）

- 不改信息架构（仍是开屏 → 主场景 → 沉浸页）
- 不改命名系统、导出逻辑、彩蛋触发条件
- 不引入 WebGL / Three.js / Lottie
- 不做主题切换 / 暗色模式
- 不做音效

## 7. 与原计划的对应

| 原计划 | 实际归属 | v0.3 在做 |
| --- | --- | --- |
| v0.3：命名库扩展 | 延后 | 本版本改为「开屏与动效体验升级」 |
| v0.4：动效打磨 | 提前并入 | 视图切换、微交互、FLIP、涟漪 |

> 一句话总结：v0.3 不是加功能，而是让 fafa 的颜色第一次出现时更温柔，让每一次触碰都有回应。
